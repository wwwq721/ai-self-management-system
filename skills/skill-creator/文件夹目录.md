# 文件夹目录

本文件是 `skill-creator` 工作文件夹的标准目录记录，也是其他 Skill 建立同名目录清单时使用的格式参考。

## 记录规则

- 只记录本文件所在工作文件夹及其下级目录，路径统一使用相对路径。
- 不记录机器绝对路径、平台用户目录或运行时临时路径。
- 目录或文件发生新建、移动、改名、删除时，完成操作后立即同步本文件。
- `references/`、`scripts/` 和 `assets/` 是否存在按 Skill 的实际需要决定，不为形式创建空目录。
- 删除落点与目录维护规则见根 [文件夹目录.md](../../文件夹目录.md)；本文件只记录本工作文件夹的实际结构。
- 工程的具体业务目录由工程自身定义，但仍使用本文件的记录字段和相对路径口径。

## 标准目录

| 相对路径 | 用途 | 必需/可选 | 当前状态 | 使用时机 |
| --- | --- | --- | --- | --- |
| `SKILL.md` | Skill 的入口说明、触发边界、工作流程和验证要求 | 必需 | 当前存在 | 触发 Skill 或维护其行为时 |
| `文件夹目录.md` | 记录本工作文件夹的标准目录结构和变更约定 | 必需 | 当前存在 | 修改目录、文件、脚本或资源前后 |
| `LICENSE.txt` | 记录 Skill 的许可证条款 | 可选 | 当前存在 | 分发、复用或确认许可边界时 |
| `_meta.json` | 发布渠道或工具使用的 Skill 元数据 | 可选 | 当前存在 | 发布或维护对应元数据时 |
| `_skillhub_meta.json` | SkillHub 使用的附加元数据 | 可选 | 当前未创建（2026-09-19 用户手动删除，未恢复） | 重新订阅或恢复市场元数据时 |
| `references/` | 按需加载的格式、流程和实现细节 | 可选 | 当前存在 | 入口规则不足以完成当前任务时 |
| `references/skill-format.md` | Skill frontmatter、命名和目录格式 | 可选 | 当前存在 | 编辑 Skill 格式或结构时 |
| `references/progressive-disclosure.md` | 渐进披露、拆分和上下文负担规则 | 可选 | 当前存在 | 设计或调整按需加载时 |
| `references/migration.md` | 从已有 Skill 提取、合并或迁移时的规则 | 可选 | 当前存在 | 进行 Skill 迁移、合并或拆分时 |
| `references/workflows.md` | 多步骤流程和条件分支的编写参考 | 可选 | 当前存在 | 需要设计复杂工作流时 |
| `references/output-patterns.md` | 固定输出格式、模板和示例 | 可选 | 当前存在 | 需要规定稳定输出形态时 |
| `scripts/` | 可重复执行的初始化、验证和打包脚本 | 可选 | 当前存在 | 需要执行对应自动化流程时 |
| `scripts/init_skill.py` | 初始化新 Skill 目录 | 可选 | 当前存在 | 创建新 Skill 时 |
| `scripts/quick_validate.py` | 快速验证 Skill 结构和内容 | 可选 | 当前存在 | 交付或打包前验证时 |
| `scripts/package_skill.py` | 生成可分发的 `.skill` 包 | 可选 | 当前存在 | 确实需要分发 Skill 时 |
| `assets/` | Skill 使用的图片、数据或其他静态资源 | 可选 | 当前未创建 | Skill 的任务确实需要随附资源时 |

## 维护边界

本文件只描述目录和文件的归属、用途及使用时机，不替代 `SKILL.md` 的行为规则、`OPERATIONS.md` 的操作门禁或平台机器事实文件。目录清单与实际结构不一致时，以实际检查结果为准并立即修订本文件。
